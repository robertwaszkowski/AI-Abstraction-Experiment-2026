# IT subtotal specification — 2 October 2026

The explicit category mapping from the Two-Level IT Skill Burden Framework is applied by Skill_ID, before exact-label deduplication within each realization. The mapping has 163 IT and 46 domain IDs. Original labels are preserved, including the historical `+Column Expressions` label for SK113, which is IT. A blanket prefix filter would incorrectly exclude that exception.

SK001/SK056 (BPMN Process Model) and SK006/SK032 (Lookup/Drop-down) are domain entries in the canonical mapping. They remain in the complete inventories, source annotations and actor/evidence matrix, but do not enter the IT subtotal. The same rule applies to Code/Model and every actor. Separately evidenced technical facets, including Control Structures (SK046), remain eligible; a domain-level BPMN or choice label does not suppress them. This is a taxonomy-defined IT subtotal, not a claim that each activity beneath a domain label lacks technical content. For example, A091 records a human choice request, A301 a technical value mapping and A303 formal gateway branching; their activity/evidence annotations are unchanged.

Eligible evidence remains observed use/report (O) or implementation-supported requirement (R), in common or starter-adaptation scope. Count the union of exact labels once across actors and contextual IDs. Unresolved rows give no positive evidence; separately supported labels may still count. Proposed taxonomy gaps remain separate. No weighting or inference of human mastery is added.

PROVENANCE.json records the source hashes and mapping hash. The explicit source matrix and catalogue sets agree exactly by ID. All 329 source-linked annotations remain available in the complete evidence inventory.
