# Inputs and reference results

Version: TSE-models-vs-code-2026-10-12-r11.

- experiments.csv: seven matched two-person teams and run pairing.
- request_counts/: recorded requests and their evidence ledger/method.
- timing_components/: derived intervals for the threshold sensitivities.
- skill_extension/ and skill_classification/: frozen annotations, taxonomy and explicit IT/domain mapping.
- reference_results/: frozen numerical results, artifact inventories, timing provenance and category summaries used for exact comparisons.
- supplement/: acceptance reports, capability evidence, task inputs, procedure/tool metadata, source/media inventories and 51 anonymized conversation-text exports.

The analysis reads these unpacked files directly. Regenerated outputs go to /results. Source records, screenshot omissions and inference limits are documented with the inputs. Manuscript and supplement documents are supplied separately. Code and data licenses are retained in their respective folders. Checksum entries for every distributed code/input file are in /code/SHA256.json.
