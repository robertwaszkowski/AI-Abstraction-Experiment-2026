# Static and documentary capability evidence

The 210 rows cover 15 capabilities in seven paired deliveries. `checklist.csv` defines each capability; `assessment.csv` provides states, suppliers, findings and source references; `sources.json` provides source locators and hashes. I means available, including through reused libraries or runtime services; P means partial/limited; N means not located; U means not determined from available evidence. These availability states are applied identically to Code and Model, and are not scores. The evidence_basis, evidence_ids and supplier columns separately record the supporting evidence and provider. Features supplied by the libraries and runtimes used by the applications count as available in both Code and Model. Supplier and evidence provenance remain explicit; availability does not claim separately observed use in each delivery. Regression-test assets may be application-specific or supplied by the reused runtime, as recorded in the findings. Source presence does not establish deployed correctness. These annotations were produced with AI assistance; no independent second assessment or new behavioral/security test was conducted.

Source paths identify the retained restricted corpus. Files cited by those paths are not all distributed in this numerical reproduction package. Unknowns and supported source-level deficiencies are retained.
